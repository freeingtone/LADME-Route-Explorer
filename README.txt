LADME Route Explorer v3.1.5
Build: 20261110-count-only-mode

Open index.html in a browser. No installation or network access is needed.
Four tabs: Anatomy, Drug journey, Pharmacology, Simulation. Simulation remains
the default tab. Tab switching preserves simulation settings and playback.

PHARMACOLOGY
Connects pharmacokinetics (body → drug) with pharmacodynamics (drug → body).
Five experiment buttons: full agonist, partial agonist, agonist + competitive
antagonist, antagonist alone, increase agonist. Sliders set concentrations,
and Advanced mode also exposes agonist Kd. The shared Beginner/Advanced switch
is available within this tab and Simulation.
Receptor icons show binding; the calculated text and curve show response.
The concentration–response graph is independent of the simulator’s time graph.
Parent-drug amounts are not converted into receptor-site concentrations.
No real-drug response, benefit, toxicity or clinical dosing prediction is made.

MODEL
One receptor binding site, reversible competition, equilibrium, zero baseline
activity, no spare receptors. Response is proportional to agonist occupancy.
Epsilon 1 (full) or 0.4 (partial); antagonist Ki 50 invented units.
Noncompetitive/inverse agonism, signaling delays, desensitization and mixed
full/partial agonists are outside this version. Existing PK equations, profiles,
dose schedules, target band, forward particles and diagnostics are retained.

ENGLISH / THAI (v3.1.3)

page is reloaded; no preference or student answer is stored or uploaded.

HOSTED COUNTER — v3.1.3
Upload index.html, analytics.php and analytics-config.php to the same directory
on a PHP 7.4+ host. The offline HTML needs only index.html and never records a
visit. Static-only hosting continues to run the lesson but cannot log IPs.
The public count is page opens with JavaScript, including reloads. It is NOT
unique visitors, concurrent viewers, bot-filtered analytics or a full HTTP log.
Changing tabs or language does not send another event.
The server records UTC access time and direct REMOTE_ADDR only. Behind a proxy
or CDN this can be the proxy address. Forwarded headers are deliberately not
trusted. No raw address or log contents are returned to the browser.
See DEPLOYMENT.md for private storage, viewing logs and retention maintenance.
